# 電気図面作成ツール（単線結線図 / 分電盤図）

ブラウザで動作する、日本の電気設備向け作図ツールです。フォームに仕様を入力すると図面を自動生成し、キャンバス上で手直しして、PDF・DXF・SVG に出力できます。バックエンドは不要で、Cloudflare Workers（Static Assets）でホストします。

## できること

| 図面 | 内容 |
| --- | --- |
| 高圧受電設備 単線結線図 | 6.6kV 受電。PAS/UGS（**ZCT + 地絡継電器**）・ケーブルヘッド・VCT・DS・LA・**主遮断装置 → CT**・計器（CT 二次 / VT 二次を分けて結線）・保護継電器・高圧母線・**高圧分岐盤（開閉装置 + CT + 継電器 + 計器 + 高圧ケーブル）**・変圧器（単相/三相・結線を選択・二次側に計器）・進相コンデンサ（SR 付） |
| 副変電所 単線結線図 | 高圧受電盤の「送り」から高圧で受ける設備。中身は受電設備と同じ作りで、盤ごとに 1 図面 |
| 分電盤 単線結線図 | 単相2線 / 単相3線 / 三相3線。主幹（ELB/MCB）と分岐回路（回路 No・種別・極数・AT・電圧・負荷名・容量・電線サイズ）。用紙に収まらない回路は次ページへ分割 |
| 盤面配置図 | 主幹と分岐ブレーカーの正面配置（奇数上段・偶数下段 または 順番配置）、N/E バー、盤外形の目安 |
| 回路表 | 分岐回路一覧表と合計容量、単相3線の L1/L2 負荷バランス。行数が多い場合は複数ページ |
| 機器銘板表 | 型式・定格容量・製造者・製造年月・製造番号・使用箇所の一覧。設備仕様から自動生成 |

- **入力**: 「仕様入力」タブのフォーム（プロジェクト情報・高圧受電設備・副変電所・分電盤）。表は行の追加・並べ替え・削除が可能
- **自動作図**: 「図面を再生成」で全図面を生成。仕様を変更すると図面に「要更新」が付きます。
  **作り直しても手で足したものは消えません**。決まった形に作り直す動作そのものを**やめることもできます**（後述）
- **手直し**: 「図面」タブで要素と配線をドラッグ、ラベル移動、部品追加、配線ツールでポート間を接続、
  テキスト追加、複製・コピー＆貼り付け、Delete で削除、Ctrl+Z / Ctrl+Y で取り消し・やり直し。
  **白紙の図面**を足して一から描くこともできます
- **出力**: 「出力」タブから PDF（ブラウザ印刷）、DXF（R12・Shift_JIS）、SVG、プロジェクト JSON
- **銘板**: 図面に描かれる機器はすべて型式・製造者・製造年月・製造番号・**数量**を入力できます。受電盤は PAS・引込ケーブル・VCT・取引用電力量計・DS・VT ヒューズ・VT・LA・CT・継電器・各計器・主遮断装置、分岐盤と分岐は開閉装置・直列リアクトル・CT・継電器・ケーブル・本体。行の「銘板」ボタンを開くと、選んだ機器のぶんだけ入力欄が並びます。機器銘板表に一覧化され、図面ラベルへの型式併記は切替式
- **Excel 取り込み**: 機器銘板表の Excel / CSV を読み込んで設備を作成（後述）
- **保存**: 手描きも含めてブラウザに自動保存。JSON で保存・読込も可能（後述）

### 変圧器の電源

変圧器の「電源」欄で、どこから給電するかを選べます。

| 選択 | 描かれ方 |
| --- | --- |
| 高圧母線に直結 | 母線から分岐 |
| 高圧分岐盤 | その分岐盤の副母線から分岐（同じ盤に複数ぶら下げられます） |
| 変圧器の二次側 | その変圧器の下に続けて描く（**低圧 → 低圧**） |
| その他の電源（名前を入力） | 母線につながず、変圧器の真上に引き込み線と名前を描く。非常電源盤・発電機盤など |

一次電圧も入力できるので、`6600 → 440 → 440 → 220` のような多段の変圧も
**1 枚の高圧単線結線図の中で数珠つなぎ**に描けます。二次側が枝分かれするときは副母線で振り分けます。
段ごとに開閉装置を挟めます（低圧側は「開閉器なし」にもできます）。

### 図面タブでの編集

自動作図はたたき台で、仕上げは図面タブで手描きできます。

- **白紙の図面を足せます**（図面一覧の「+ 白紙」）。仕様に紐づかないので作り直しの対象になりません。
  自動生成の図面を **⧉（複製）** すると、仕様から切り離した写しになります（名前変更は ✎、削除は ✕）
- **端子は常に薄く表示**されます。「配線」ツールに切り替えると濃くなり、端子どうしをクリックしてつなげます
- **部品はクリックした位置に置きます**。パレットで部品を選ぶと配置モードになり、図面をクリックすると
  そこに置かれます（Esc で取り消し）
- **配線の上をクリックすると、その線の途中に入ります**。線が 2 本に分かれて上流・下流につながるので、
  「PF と SR の間に VCS を入れる」が 1 操作で済みます。隙間が足りないときは同じ列の下流側が下にずれます
- **配線をドラッグすると曲がりの位置を動かせます**。端の線分を動かしても端子は動きません
  （プロパティ欄の「自動配線に戻す」で元に戻せます）
- **機器をドラッグすると、つながっている相手の中心線に吸い付きます**（3mm 以内）。線が折れ曲がりません
- **手で足した機器には銘板を入力できます**（プロパティ欄）。機器銘板表に 1 行として出ます。
  自動作図の機器は仕様側の銘板を使うので、二重には出ません
- **複数選んで整列できます**（右のプロパティ欄）。縦にも横にも揃えられます

| 操作 | キー |
| --- | --- |
| 複製 | Ctrl+D |
| コピー / 貼り付け / 切り取り | Ctrl+C / Ctrl+V / Ctrl+X（**図面をまたげます**） |
| 微動 | 矢印キー（1 刻み） / Shift+矢印（5 刻み） |
| 取り消し / やり直し | Ctrl+Z / Ctrl+Y |

**スナップ（移動の刻み）** は図面右下で `0.5 / 1 / 2.5 / 5mm` と「なし」から選べます（既定 1mm）。
**Alt を押している間はスナップしません**。格子の表示も刻みに追随します。

| 整列 | 内容 |
| --- | --- |
| 縦に並べる（左右をそろえる） | 左 / 左右中央 / 右 |
| 横に並べる（上下をそろえる） | 上 / 上下中央 / 下 |
| 等間隔に並べる | 左右 / 上下（3 台以上。両端は動かしません） |

**左右中央・上下中央**は図記号の中心線をそろえるので、つないだ配線が真っすぐになります
（左・右・上・下は外形の端でそろえます）。動くのは図記号だけで、配線は自動で引き直します。

### 図面を作り直しても手作業は消えません

「図面を再生成」は仕様から作り直しますが、手を入れたものは新しい図面へ載せ替えます。

| | 扱い |
| --- | --- |
| 手で足した機器・配線・文字 | **残る** |
| 入力した銘板、動かしたラベル、手直しした配線の経路 | **残る** |
| 白紙の図面・複製した図面 | **触られない**（仕様に紐づかないため） |
| 自動作図した機器の位置・向き・ラベル | 仕様どおりに引き直す |

作り直しは履歴 1 手なので **Ctrl+Z で丸ごと取り消せます**。
手直しのある図面があるときだけ、何が残り何が戻るかを確認するダイアログが出ます。

つなぎ先の機器が仕様から消えた手描き配線は、端をその場に固定して警告でお知らせします。

### 自動作図をやめて、手描きを主にする

決まった形に作り直す動作が不要なときは、「プロジェクト情報」の **自動作図: 仕様から図面を作る** を外します。

| | 自動作図 オン（既定） | 自動作図 オフ |
| --- | --- | --- |
| 単線結線図 | 仕様から作る | **作らない**（「全て再生成」「↻」も出ません） |
| 機器銘板表 | 仕様 ＋ 手描きの機器 | **図面に置いた機器だけ**から作る |
| 銘板の入力 | 手描きの機器（仕様の機器は仕様側で入力） | **図面のどの機器でも**入力できる |
| 更新 | 「全て再生成」 | **「銘板表を更新」**（単線結線図には触りません） |

オフのときの流れは **「+ 白紙」→ パレットから図記号を置く → プロパティ欄で銘板を入力 → 「銘板表を更新」** です。
図面に置いた順ではなく、図面の並び順・置いた順に行が並びます。

図面 1 枚だけ仕様から外したいときは、図面一覧の **⛓** を押します（絵はそのままで、以後は作り直しの対象になりません）。

### 保存と読み込み

**手で描いた内容も含めて、操作するたびにブラウザへ自動保存されます**（localStorage、0.5 秒後。ドラッグ中は保存せず、離した時点で 1 回）。
タブを閉じても、次に開いたときに続きから始められます。保存ボタンを押す必要はありません。

| やりたいこと | 操作 |
| --- | --- |
| 続きを描く | そのまま開き直すだけ（自動保存から復元） |
| ファイルに残す・別の PC へ渡す | ヘッダーの **「保存 (JSON)」**（`.elec.json` がダウンロードされます） |
| 保存したファイルを開く | ヘッダーの **「開く」** |
| 図面として渡す | 「出力」タブの PDF / DXF / SVG |

自動保存はそのブラウザの中だけに残ります。**別の PC・別のブラウザ・シークレットウィンドウでは見えず、
ブラウザの閲覧データを消すと消えます**。残しておきたい状態は JSON で保存してください（新規作成でも上書きされます）。

### 用紙に収める仕組み

機器を増やしても図面が用紙からはみ出さないよう、2 段階で調整します。

1. **ページ分割** — 高圧母線の分岐、分電盤の回路、回路表・銘板表の行が 1 枚に入らない場合は次ページへ送ります。図面から機器が黙って消えることはありません
2. **自動縮尺** — それでも収まらない場合は図記号ごと一様に縮小します。適用した縮尺は表題欄に `1:1.36` のように表示されます

高圧単線結線図では、変圧器を分岐盤に所属させると 1 区画にまとまるため枚数を減らせます。

**高さは自動でそろえます。** 開閉装置の数が分岐ごとに違っても、変圧器・進相コンデンサは同じ高さに
並びます（開閉装置は基準線の直上に下詰め）。副母線の高さも全分岐盤で共通で、母線直結の分岐も同じ列に並びます。
同じ分岐盤から複数の系統が出る場合は、**盤ごとに破線で囲んで盤名を付ける**ので、どの系統がどの盤のものか分かります。

**文字も重なりません。** 列の間隔はいちばん長い機器名・定格の幅から決めるので、
`低圧生産動力No.1-2` のような長い名前でも隣の列とぶつかりません。
図記号やラベルが重なっていたら警告でお知らせします（検出は `src/layout/overlap.ts`、テストで 0 件を要求）。

### 並べ替え

図面上の並びは仕様の並び順そのままです。

- **高圧分岐盤・変圧器・進相コンデンサ** — 各表の「並び」列の ← → で母線上の左右が入れ替わります
- **開閉装置・継電器** — チェックした下に並びが出るので、↑↓（← →）で順番を変えられます。
  「既定順」でいつでも標準の並びに戻せます

チェックを入れたときは既定順の位置に差し込むので、手で入れ替えた並びは崩れません。
なお**母線直結の機器は分岐盤より右**にまとめて描きます。

図記号は JIS C 0617 の様式を参考にした自作の近似図形です（`src/symbols/`）。忠実度は目視で確認し、必要に応じて定義を修正してください。

### 作図の決まり

| 決まり | 理由 |
| --- | --- |
| 主回路は中太線、**計器・制御回路は細線**（DXF は `CONTROL` レイヤ） | 主回路と計器回路を線の太さで区別する慣例に合わせています |
| 受電部は **主遮断装置 → CT → 母線** の順 | CT を主遮断装置の負荷側に置けば、遮断器を開いたときに CT 以降が無充電になります。分岐盤の見出し（開閉器 → CT）とも並びがそろいます |
| **VT の一次側に限流ヒューズ（VT ヒューズ）を入れる** | 計器用変圧器は一次側をヒューズで保護します。既定では VT の真上・同じ列に縦に入れ、直列の 2 台をそろえます |
| **接地線は避雷器（LA）の A種だけ描く** | 単線結線図に接地をすべて描くと図が混みます。必要なら接地記号をパレットから手で置けます |
| **高圧進相コンデンサの下端は接地しない** | 単線結線図では他相へつながる端子で、接地端子ではありません |
| 電流計は CT 二次（継電器・AS と直列）、電圧計は VT 二次（VS 経由）、電力計・力率計・電力量計は両方 | 計測する量ごとに回路が違います（後述） |
| 変圧器・コンデンサの本体は段ごとに高さをそろえる | 開閉装置の数が違っても図面が読みやすくなります |

### 開閉装置の組み合わせ

**DTMC / PF付LBS / LBS / VCB / MCCB / PC / PF / VCS** をチェックボックスで足し引きします。
変圧器・進相コンデンサ・高圧分岐盤・受電盤の主遮断装置のどこでも同じ選び方です。

- 「限流ヒューズ (PF) だけ」「LBS だけ」といった構成も作れます
- 全部外すと **開閉器なし**（母線・分岐盤に直結）になります
- 既定の並びは上流→下流（**DTMC → PF付LBS → LBS → VCB → MCCB → PC → PF → VCS**）で、
  チェックを入れるとその位置に差し込まれます。**↑↓ で自由に入れ替えられます**
- **PF付LBS** は限流ヒューズ付高圧交流負荷開閉器を 1 台として描きます（LBS と PF を別々に選んだ場合は 2 台に分かれます）
- **MCCB**（配線用遮断器）は低圧用変圧器の一次側などに使います。定格の表記は 600V 系になります
- **DTMC** はダブルスロー（双投）の切替開閉器です。発電系統と受電系統の切替に使い、
  発電側に引き出し線と「発電系統」の注記を描きます
- 限流ヒューズの定格は PF を含むとき、遮断容量は VCB / MCCB を含むときだけ入力できます

VCS は単体では短絡電流を遮断できません。実機の構成に合わせて LBS + PF + VCS を選ぶのが一般的です。

### 変圧器の結線

三相変圧器は結線を選べます。重なる 2 円の中に一次側・二次側それぞれの巻線記号を描きます。

**Δ-Δ（既定） / Δ-Y / Y-Δ / Y-Y / V-V / スコット結線**

既定の Δ-Δ は図面ラベル・銘板表に書きません（従来の見た目のまま）。それ以外は
`3φ 100kVA 6.6kV/210V Δ-Y` のように併記します。単相は結線を持ちません。

### 保護継電器

受電盤と高圧分岐盤で、継電器をチェックで足し引きできます（並べ替えも同じ）。

| 記号 | 名称 | 器具番号 | つなぐ回路 |
| --- | --- | --- | --- |
| OCR | 過電流継電器 | 51 | CT 二次 |
| OCGR | 地絡過電流継電器 | 51G | ZCT 二次 |
| DGR | 地絡方向継電器 | 67G | ZCT 二次 + VT 二次 |
| OVGR | 地絡過電圧継電器 | 64 | VT 二次 |
| UVR / OVR | 不足電圧 / 過電圧継電器 | 27 / 59 | VT 二次 |
| RPR | 逆電力継電器 | 67P | CT 二次 + VT 二次 |
| UFR / OFR | 不足 / 過周波数継電器 | 81U / 81O | VT 二次 |
| その他 | 名称をラベルで打つ無地の箱 | — | CT 二次 |

CT 二次の継電器は CT のすぐ右に直列で、VT 二次だけの継電器は電圧回路の横母線につなぎます。
以前の「OCR」チェックだけのデータは自動で `OCR` に移行します。

### 区分開閉器の地絡保護

「引込・区分開閉器」の **地絡保護** 欄で、ZCT（零相変流器）と継電器を選べます（既定は SOG 付＋DGR）。

- ZCT は **区分開閉器の下・ケーブルヘッドの上**に入り、その二次から継電器へ細線でつなぎます
- 継電器を選ぶと ZCT が無くても足します（その旨を警告で知らせます）
- 複数選ぶと ZCT 二次に直列で並びます（並べ替えは受電盤の継電器と同じ）
- 零相電圧を使う継電器（OVGR など）は、実際には ZVT/EVT から取るため警告でお知らせします
- 銘板は ZCT・継電器それぞれに入力でき、機器銘板表には備考「引込」で出ます

古いデータで DGR の銘板だけ入っている場合は、DGR を選んだものとして扱います。

### 副変電所

高圧受電盤から「送り」（高圧分岐盤）を出して、その先に別の受変電設備がある構成に対応します。

- 仕様ナビの「副変電所（送りの先）」で追加します。入力欄は受電設備と同じで、
  引込・区分開閉器・取引用計器のかわりに受電ケーブルだけを持ちます
- 「電源（送り）」で親のどの分岐盤から受けるかを選ぶと、
  **親の図面ではその盤の囲みに「→ 副変電所No.1」**、
  **副変電所の図面は「高圧受電盤 送りNo.2 より」**から始まります
- 図面は盤ごとに別ページ、機器銘板表は備考の頭に盤名を付けて 1 つの表にまとめます

### VT ヒューズの向き

「計器」欄の下の **VT ヒューズ**で、縦・横を選べます。

| 選択 | 描き方 |
| --- | --- |
| 縦（既定） | VT の真上・同じ列に入れる。直列の 2 台と引き下げ線がそろう |
| 横 | 引き出し線の途中に横向きで入れる。縦を 20mm 詰められる |

用紙に収めることを優先したいときは「横」を選んでください。

### 計器の結線

計器は使う量に応じて別の回路につなぎます。

| 計器 | つなぐ回路 |
| --- | --- |
| 電流計 (A) | CT 二次（5A 回路）。**継電器 → AS（電流計切換開閉器）→ A** と直列 |
| 電圧計 (V) | VT 二次（110V 回路）。**VS（電圧計切換開閉器）** を介してつなぐ |
| 電力計 (W)・力率計 (cosφ)・電力量計 (Wh) | 電流コイルは CT 二次、電圧コイルは VT 二次 |

力率計は **cosφ** と表記します（限流ヒューズの PF と紛らわしいため）。
AS・VS は「計器切換開閉器」欄で外せます。

**高圧分岐盤と変圧器の二次側**にも同じ作りで電流計・電圧計を付けられます。

| 場所 | 入力 | 描き方 |
| --- | --- | --- |
| 高圧分岐盤 | 分岐盤の表の「計器」欄（A / V、選ぶと AS / VS） | 盤の CT 二次に **継電器 → AS → A**、VT を立ててその二次に **VS → V** |
| 変圧器の二次側 | 変圧器の表の「二次計器」欄 | 二次線に CT を入れて同じ並び。負荷矢印はそのぶん下がります |

変圧器の二次側にさらに変圧器がつながっている場合は描けないので、警告でお知らせします。

主遮断装置が PF・S 形で保護用 CT が無い場合、電流回路の計器があれば計器用 CT を追加します（その旨を警告で知らせます）。

## 使い方

1. 「仕様入力」でプロジェクト情報（図面名・図番・日付・作成者・用紙）を入力
2. 「高圧受電設備」で受電方式・機器・変圧器・コンデンサを入力（不要なら「有効」を外す）
3. 「分電盤」で主幹と分岐回路を入力。「+ 分電盤を追加」で複数面に対応
4. ヘッダーの「図面を再生成」を押し、「図面」タブで確認・手直し
5. 「出力」タブで PDF / DXF / SVG を出力

### PDF 出力の注意

ブラウザの印刷ダイアログで「PDF に保存」を選び、用紙 A3（または A4）横・余白なし・倍率 100%・「ヘッダーとフッター」オフに設定してください。図枠と表題欄は図面の中に含まれています。

## Excel から機器銘板を取り込む

ツールバーの「Excel 取り込み」から、機器銘板表の Excel（.xlsx）や CSV を読み込めます。

対応する列は **機器名称 / 型式 / 定格容量 / 製造者 / 製造年月 / 製造番号 / 使用箇所 / 備考** です。
見出し行と列の対応は自動で判定し、画面上で変更できます。ページ区切りで繰り返される見出し行や表題行は自動で除きます。

**備考欄の盤名で機器を振り分けます。**

| 備考の例 | 作られるもの |
| --- | --- |
| 柱上 / 200sq 250m CVT | 引込（区分開閉器・引込ケーブル） |
| 高圧受電盤 | 受電盤の各機器（DS・VT・LA・VCB・CT・OCR など） |
| 高圧分岐盤No.1 F1 / コンデンサ盤No.1 | 高圧分岐盤（開閉装置 + CT + OCR + ケーブル） |
| No.1 SC | 進相コンデンサ（SC + SR + 開閉器） |
| 低圧設備動力No.1 / 事務棟 電灯 | 変圧器と、その給電先の分電盤 |

定格容量は自由記述のまま解釈します（`500kVA 6600/440`・`7.2kV600A 12.5kA`・`6900V 400/5`・`50kvar 6600V`・`7.2kV G20` など）。
読み取れない場合も原文をそのまま銘板に残します。全角英数・全角ハイフン・ふりがなの表記ゆれは自動で整えます。

開閉装置は同じ盤にある機器の行から判定します（VCB があれば VCB、LBS と VCS が揃えば LBS+PF+VCS、など）。

取り込む前に内容を一覧で確認でき、「置き換え」か「追加」を選べます。取り込みは「元に戻す」1 回で取り消せます。

### 取り込みで決まらないこと

- **分岐盤と変圧器の対応**は台帳に情報が無いため、取り込み直後は変圧器が高圧母線に直結した状態になります。「高圧受電設備」画面の変圧器一覧にある「所属分岐盤」欄で選び直してください
- 図面に描けない補機（制御用機器など）や、同じ位置に 2 台目がある機器は、機器銘板表にのみ載せます
- 低圧の分岐回路は台帳に無いため、分電盤は主幹のみの状態で作られます

### DXF 出力の注意

- DXF R12（AC1009）ASCII、単位 mm、原点は用紙左下。JW-CAD / AutoCAD / LibreCAD で読み込めます
- ファイル名は図番と図面種別から ASCII のみで作ります（例: `E-001_hv-sld.dxf`、`E-001_lv-schedule_L-1_p2.dxf`）。ブラウザや CAD が非 ASCII のファイル名を落とすことがあるためです
- 複数の図面をまとめて出力すると、ブラウザが「複数のファイルのダウンロード」の許可を尋ねることがあります
- 文字コードは既定で Shift_JIS（`$DWGCODEPAGE = ANSI_932`、bigfont.shx 指定）。JW-CAD / AutoCAD 日本語版向けの慣例です。日本語以外のロケールの CAD では文字化けする可能性があるため、UTF-8 も選べます（互換性は環境依存）
- R12 には線幅がないため、レイヤ `FRAME` / `BUS` / `WIRE` / `CONTROL`（計器回路）/ `SYMBOL` / `TEXT` / `TABLE` と色（BUS のみ色 1）で区別しています。CAD 側でレイヤごとにペン幅を割り当ててください

## Cloudflare へのデプロイ

Cloudflare Workers の Static Assets 機能で `dist/` を配信します（設定は `wrangler.jsonc`）。
デプロイ先の Worker 名は **`electric`**、公開 URL は `https://electric.<サブドメイン>.workers.dev` になります。

### 手元から

```bash
npx wrangler login
npm run deploy
```

複数の Cloudflare アカウントに所属している場合は、対象アカウントを環境変数で指定します。

```bash
CLOUDFLARE_ACCOUNT_ID=<アカウント ID> npm run deploy
```

### GitHub Actions から

リポジトリの Secrets に以下を登録すると、**既定ブランチへの push で自動デプロイ**されます（未登録の場合、デプロイ手順はスキップされビルドとテストだけが走ります）。

| Secret | 内容 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | 「Workers スクリプトの編集」権限を持つ API トークン |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare ダッシュボードのアカウント ID |

アカウント ID は公開リポジトリに残さないよう、`wrangler.jsonc` には書かず Secrets / 環境変数から渡す方針にしています。

## 制限事項

- 容量計算・保護協調・電線サイズの妥当性は検証しません（入力値をそのまま描画）
- 用紙に収まらない図面はページ分割と自動縮小で対応しますが、盤面配置図は 1 枚の盤の正面図のため分割できません。回路数が多い場合は A3 横をお使いください
- 1 つの分岐盤にぶら下がる機器が極端に多い場合は分割できないため、縮尺の下限（1:2.86）で頭打ちになり警告が出ます
- 図面を再生成すると、**自動作図した機器の位置・向き・ラベル**は仕様どおりに引き直します
  （手で足した機器・配線・文字、銘板、ラベル位置、手直しした配線の経路は残ります。Ctrl+Z で取り消せます）
- 母線直結の機器は高圧分岐盤より右にまとめて描きます。分岐盤の間に挟むことはできません
- 図記号は JIS C 0617 の様式を参考にした自作の近似図形です。正式な提出図面に使う場合は目視で確認してください
