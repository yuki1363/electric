# 電気図面作成ツール（単線結線図 / 分電盤図）

ブラウザで動作する、日本の電気設備向け作図ツールです。フォームに仕様を入力すると図面を自動生成し、キャンバス上で手直しして、PDF・DXF・SVG に出力できます。バックエンドは不要で、Cloudflare Workers（Static Assets）でホストします。

## できること

| 図面 | 内容 |
| --- | --- |
| 高圧受電設備 単線結線図 | 6.6kV 受電。PAS/UGS・ケーブルヘッド・VCT・DS・主遮断装置（CB 形 / PF・S 形）・LA・計器（CT 二次 / VT 二次を分けて結線）・高圧母線・**高圧分岐盤（開閉装置 + CT + OCR）**・変圧器（単相/三相）・進相コンデンサ（SR 付）・接地 |
| 分電盤 単線結線図 | 単相2線 / 単相3線 / 三相3線。主幹（ELB/MCB）と分岐回路（回路 No・種別・極数・AT・電圧・負荷名・容量・電線サイズ）。用紙に収まらない回路は次ページへ分割 |
| 盤面配置図 | 主幹と分岐ブレーカーの正面配置（奇数上段・偶数下段 または 順番配置）、N/E バー、盤外形の目安 |
| 回路表 | 分岐回路一覧表と合計容量、単相3線の L1/L2 負荷バランス。行数が多い場合は複数ページ |
| 機器銘板表 | 型式・定格容量・製造者・製造年月・製造番号・使用箇所の一覧。設備仕様から自動生成 |

- **入力**: 「仕様入力」タブのフォーム（プロジェクト情報・高圧受電設備・分電盤）。回路表は行の追加・並べ替え・削除が可能
- **自動作図**: 「図面を再生成」で全図面を生成。仕様を変更すると図面に「要更新」が付きます
- **手直し**: 「図面」タブで要素をドラッグ（5mm 格子スナップ、接続配線は自動追従）、ラベル移動、部品追加、配線ツールでポート間を接続、テキスト追加、Delete で削除、Ctrl+Z / Ctrl+Y で取り消し・やり直し
- **出力**: 「出力」タブから PDF（ブラウザ印刷）、DXF（R12・Shift_JIS）、SVG、プロジェクト JSON
- **銘板**: 図面に足せる機器はすべて型式・製造者・製造年月・製造番号を入力できます（開閉装置・直列リアクトル・CT・OCR・ケーブルを含む）。行の「銘板」ボタンを開くと、選んだ機器のぶんだけ入力欄が並びます。機器銘板表に一覧化され、図面ラベルへの型式併記は切替式
- **Excel 取り込み**: 機器銘板表の Excel / CSV を読み込んで設備を作成（後述）
- **保存**: ブラウザの localStorage に自動保存。JSON で保存・読込も可能

### 変圧器の電源

変圧器の「電源」欄で、どこから給電するかを選べます。

| 選択 | 描かれ方 |
| --- | --- |
| 高圧母線に直結 | 母線から分岐 |
| 高圧分岐盤 | その分岐盤の副母線から分岐（同じ盤に複数ぶら下げられます） |
| 変圧器の二次側 | その変圧器の下に続けて描く（**低圧 → 低圧**） |

一次電圧も入力できるので、`6600 → 440 → 440 → 220` のような多段の変圧も
**1 枚の高圧単線結線図の中で数珠つなぎ**に描けます。二次側が枝分かれするときは副母線で振り分けます。
段ごとに開閉装置を挟めます（低圧側は「開閉器なし」にもできます）。

### 図面タブでの編集

- **端子は常に薄く表示**されます。「配線」ツールに切り替えると濃くなり、端子どうしをクリックしてつなげます
- **部品はクリックした位置に置きます**。パレットで部品を選ぶと配置モードになり、図面をクリックすると
  そこに置かれます（Esc で取り消し）
- **配線の上をクリックすると、その線の途中に入ります**。線が 2 本に分かれて上流・下流につながるので、
  「PF と SR の間に VCS を入れる」が 1 操作で済みます。隙間が足りないときは同じ列の下流側が下にずれます
- **機器をドラッグすると、つながっている相手の中心線に吸い付きます**（3mm 以内）。線が折れ曲がりません

### 用紙に収める仕組み

機器を増やしても図面が用紙からはみ出さないよう、2 段階で調整します。

1. **ページ分割** — 高圧母線の分岐、分電盤の回路、回路表・銘板表の行が 1 枚に入らない場合は次ページへ送ります。図面から機器が黙って消えることはありません
2. **自動縮尺** — それでも収まらない場合は図記号ごと一様に縮小します。適用した縮尺は表題欄に `1:1.36` のように表示されます

高圧単線結線図では、変圧器を分岐盤に所属させると 1 区画にまとまるため枚数を減らせます。

**高さは自動でそろえます。** 開閉装置の数が分岐ごとに違っても、変圧器・進相コンデンサは同じ高さに
並びます（開閉装置は基準線の直上に下詰め）。副母線の高さも全分岐盤で共通で、母線直結の分岐も同じ列に並びます。
同じ分岐盤から複数の系統が出る場合は、**盤ごとに破線で囲んで盤名を付ける**ので、どの系統がどの盤のものか分かります。

図記号は JIS C 0617 の様式を参考にした自作の近似図形です（`src/symbols/`）。忠実度は目視で確認し、必要に応じて定義を修正してください。

### 開閉装置の組み合わせ

**LBS / VCB / PC / PF / VCS** をチェックボックスで足し引きします。
変圧器・進相コンデンサ・高圧分岐盤・受電盤の主遮断装置のどこでも同じ選び方です。

- 「限流ヒューズ (PF) だけ」「LBS だけ」といった構成も作れます
- 全部外すと **開閉器なし**（母線・分岐盤に直結）になります
- 選んだ機器は上流→下流（**LBS → VCB → PC → PF → VCS**）の順に並べ替えて描きます。
  チェックした順番は関係ありません
- 限流ヒューズの定格は PF を含むとき、遮断容量は VCB を含むときだけ入力できます

VCS は単体では短絡電流を遮断できません。実機の構成に合わせて LBS + PF + VCS を選ぶのが一般的です。

### 計器の結線

計器は使う量に応じて別の回路につなぎます。

| 計器 | つなぐ回路 |
| --- | --- |
| 電流計 (A) | CT 二次（5A 回路）。OCR と直列 |
| 電圧計 (V) | VT 二次（110V 回路） |
| 電力計 (W)・力率計 (PF)・電力量計 (Wh) | 電流コイルは CT 二次、電圧コイルは VT 二次 |

主遮断装置が PF・S 形で保護用 CT が無い場合、電流回路の計器があれば計器用 CT を追加します（その旨を警告で知らせます）。

## 使い方

1. 「仕様入力」でプロジェクト情報（図面名・図番・日付・作成者・用紙）を入力
2. 「高圧受電設備」で受電方式・機器・変圧器・コンデンサを入力（不要なら「有効」を外す）
3. 「分電盤」で主幹と分岐回路を入力。「+ 分電盤を追加」で複数面に対応
4. ヘッダーの「図面を再生成」を押し、「図面」タブで確認・手直し
5. 「出力」タブで PDF / DXF / SVG を出力

### PDF 出力の注意

ブラウザの印刷ダイアログで「PDF に保存」を選び、用紙 A3（または A4）横・余白なし・倍率 100%・「ヘッダーとフッター」オフに設定してください。図枠と表題欄は図面の中に含まれています。

## Excel から機器銘板を取り込む

ツールバーの「Excel 取り込み」から、機器銘板表の Excel（.xlsx）や CSV を読み込めます。

対応する列は **機器名称 / 型式 / 定格容量 / 製造者 / 製造年月 / 製造番号 / 使用箇所 / 備考** です。
見出し行と列の対応は自動で判定し、画面上で変更できます。ページ区切りで繰り返される見出し行や表題行は自動で除きます。

**備考欄の盤名で機器を振り分けます。**

| 備考の例 | 作られるもの |
| --- | --- |
| 柱上 / 200sq 250m CVT | 引込（区分開閉器・引込ケーブル） |
| 高圧受電盤 | 受電盤の各機器（DS・VT・LA・VCB・CT・OCR など） |
| 高圧分岐盤No.1 F1 / コンデンサ盤No.1 | 高圧分岐盤（開閉装置 + CT + OCR + ケーブル） |
| No.1 SC | 進相コンデンサ（SC + SR + 開閉器） |
| 低圧設備動力No.1 / 事務棟 電灯 | 変圧器と、その給電先の分電盤 |

定格容量は自由記述のまま解釈します（`500kVA 6600/440`・`7.2kV600A 12.5kA`・`6900V 400/5`・`50kvar 6600V`・`7.2kV G20` など）。
読み取れない場合も原文をそのまま銘板に残します。全角英数・全角ハイフン・ふりがなの表記ゆれは自動で整えます。

開閉装置は同じ盤にある機器の行から判定します（VCB があれば VCB、LBS と VCS が揃えば LBS+PF+VCS、など）。

取り込む前に内容を一覧で確認でき、「置き換え」か「追加」を選べます。取り込みは「元に戻す」1 回で取り消せます。

### 取り込みで決まらないこと

- **分岐盤と変圧器の対応**は台帳に情報が無いため、取り込み直後は変圧器が高圧母線に直結した状態になります。「高圧受電設備」画面の変圧器一覧にある「所属分岐盤」欄で選び直してください
- 図面に描けない補機（制御用機器など）や、同じ位置に 2 台目がある機器は、機器銘板表にのみ載せます
- 低圧の分岐回路は台帳に無いため、分電盤は主幹のみの状態で作られます

### DXF 出力の注意

- DXF R12（AC1009）ASCII、単位 mm、原点は用紙左下。JW-CAD / AutoCAD / LibreCAD で読み込めます
- ファイル名は図番と図面種別から ASCII のみで作ります（例: `E-001_hv-sld.dxf`、`E-001_lv-schedule_L-1_p2.dxf`）。ブラウザや CAD が非 ASCII のファイル名を落とすことがあるためです
- 複数の図面をまとめて出力すると、ブラウザが「複数のファイルのダウンロード」の許可を尋ねることがあります
- 文字コードは既定で Shift_JIS（`$DWGCODEPAGE = ANSI_932`、bigfont.shx 指定）。JW-CAD / AutoCAD 日本語版向けの慣例です。日本語以外のロケールの CAD では文字化けする可能性があるため、UTF-8 も選べます（互換性は環境依存）
- R12 には線幅がないため、レイヤ `FRAME` / `BUS` / `WIRE` / `SYMBOL` / `TEXT` / `TABLE` と色（BUS のみ色 1）で区別しています。CAD 側でレイヤごとにペン幅を割り当ててください

## 開発

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173、?gallery で図記号一覧）
npm test           # 単体テスト (vitest)
npm run typecheck  # 型検査
npm run build      # dist/ に本番ビルド
```

### 構成

```
src/model      データモデル・開閉装置・既定値・JSON 保存/読込
src/symbols    図記号（プリミティブ列＋ポート）
src/layout     図枠・配線ルータ・自動レイアウト生成器（hvSld / lvSld / lvFace / lvSchedule / nameplate）・自動縮尺
src/render     SVG/DXF 共通の平坦化とSVG出力
src/import     Excel/CSV 読み取り・銘板表の解析・取り込み計画
src/export     DXF ライタ・エンコード・印刷・ダウンロード
src/state      reducer・履歴（Undo/Redo）・自動保存
src/ui         フォーム・キャンバス・パレット・プロパティ・出力
tests          単体テスト（生成器・ルータ・自動縮尺・DXF・取り込み・履歴・JSON・入力欄）
```

## Cloudflare へのデプロイ

Cloudflare Workers の Static Assets 機能で `dist/` を配信します（設定は `wrangler.jsonc`）。
デプロイ先の Worker 名は **`electric`**、公開 URL は `https://electric.<サブドメイン>.workers.dev` になります。

### 手元から

```bash
npx wrangler login
npm run deploy
```

複数の Cloudflare アカウントに所属している場合は、対象アカウントを環境変数で指定します。

```bash
CLOUDFLARE_ACCOUNT_ID=<アカウント ID> npm run deploy
```

### GitHub Actions から

リポジトリの Secrets に以下を登録すると、**既定ブランチへの push で自動デプロイ**されます（未登録の場合、デプロイ手順はスキップされビルドとテストだけが走ります）。

| Secret | 内容 |
| --- | --- |
| `CLOUDFLARE_API_TOKEN` | 「Workers スクリプトの編集」権限を持つ API トークン |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare ダッシュボードのアカウント ID |

アカウント ID は公開リポジトリに残さないよう、`wrangler.jsonc` には書かず Secrets / 環境変数から渡す方針にしています。

## 制限事項

- 容量計算・保護協調・電線サイズの妥当性は検証しません（入力値をそのまま描画）
- 用紙に収まらない図面はページ分割と自動縮小で対応しますが、盤面配置図は 1 枚の盤の正面図のため分割できません。回路数が多い場合は A3 横をお使いください
- 1 つの分岐盤にぶら下がる機器が極端に多い場合は分割できないため、縮尺の下限（1:2.86）で頭打ちになり警告が出ます
- 手動編集した図面は、再生成すると編集内容が失われます（確認ダイアログあり）
